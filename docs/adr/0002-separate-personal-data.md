# ADR-0002: 個人データをリポジトリから分離する

- Status: Accepted
- Date: 2026-09-12

## Context

このリポジトリは以下を含む。

- **公開したいもの**: アプリのコード、設計ドキュメント、分析ロジック（ポートフォリオとしての価値）
- **公開できないもの**: 体重・体脂肪率・周囲長の実記録、身体写真、血液検査結果（テストステロン値等の医療情報）、個人の3カ年計画

リポジトリを public にする方針を決めたため、この2つを分離する必要が生じた。

## Decision

**`private/` ディレクトリに個人データを隔離し、`.gitignore` で除外する。**

```
private/                 ← .gitignore
├── config.json          個人の身体データ・計画設定
├── data/                実記録・写真・血液検査
├── docs/                個人の3カ年計画・月次目標・栄養設計・大会準備
└── reports/             生成された週次レポート

data/sample/             ← コミットする（架空の記録）
config.example.json      ← コミットする（設定の雛形）
```

分析スクリプトのデフォルトパスを `private/` に向け、デモ実行時のみ `--data-dir data/sample` で切り替える。

## Alternatives considered

**A. リポジトリを private にする**
却下。ポートフォリオとして公開する目的が達成できない。

**B. 実データもコミットする（public のまま）**
却下。体重・挙上重量までは許容範囲だが、**身体写真と血液検査結果は公開すべきでない**。また写真はバイナリのため git 履歴を肥大化させる。

**C. 数値を匿名化して公開する**
却下。個人の3カ年計画は数値が本体であり、匿名化すると文書の意味が失われる。分離の方が単純で安全。

## Consequences

**良い影響**

- コード・設計・分析ロジックを全て公開できる
- `data/sample/` により、clone した第三者が分析を実行できる（**動かせないポートフォリオは読まれない**）
- 個人データの流出経路が物理的に存在しない

**悪い影響 / 受け入れるコスト**

- **実データのバックアップが別途必要になる。** git 管理下にないため、`private/` は iCloud 等で別途バックアップする運用が前提
- サンプルデータと実データの2系統を維持する必要がある
- `private/` を誤って `git add -f` しないよう注意が必要
